# Traffic Sign Recognition using CNN

A computer vision project for classifying traffic signs using Convolutional Neural Networks (CNNs) and PyTorch.

The project focuses on understanding the complete image classification pipeline, from image preprocessing and CNN-based feature extraction to model evaluation and transfer learning.

## Objectives

- Understand the fundamentals of Convolutional Neural Networks
- Build an image classification pipeline using PyTorch
- Perform image preprocessing and data augmentation
- Train and evaluate a custom CNN
- Experiment with transfer learning using pretrained models
- Analyze model performance using classification metrics
- Build a simple interface for traffic sign prediction
